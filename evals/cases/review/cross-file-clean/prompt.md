Review the pull request in this directory. PR.md is the author's description, change.diff is the diff against the base branch, and the tree is the pull request's head. Write review.json as {"verdict": "approve" or "needs_changes", "findings": [{"file": "path/in/tree.py", "line": 1, "blocking": true, "title": "...", "trigger": "...", "impact": "..."}]}. A finding is blocking when it must be fixed before merge. Line numbers refer to files in the tree. Do not modify any other file.
