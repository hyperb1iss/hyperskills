Operational source span selection picks a window of adjacent observations from one source. When a source has any observation that was sliced into passages, every other observation in that source is confined to a window of one, including the ones left whole. A source with one sliced observation and three whole observations that all match the query returns one row instead of three.

Size each run of the window by what that run holds. Passages stay confined to the body they were cut from and keep their fixed passage window. Whole observations keep sliding across observations at the size the caller asked for, whether or not a sibling observation was sliced. The rule that an item budget may not cut a window short applies only when the selected window is made of passages. A source with no passages must behave exactly as before.
