The memory-scope check that search applies to each result treats a named project filter as the authorized project set outright. On a surface where the project comes straight from a caller argument next to the caller's real membership set, naming a project the caller does not belong to returns that project's rows.

When both a named project and a membership set are supplied, deny unless the named project is in the membership set. When no membership set is supplied, because the caller verified access itself, the named project stands alone as before.
